1. **Should fix — [writer queues and memory](/home/luisc/Work/bend-projects/framebender-gz/notes/compress.md:749).** No queue capacity or ownership rule prevents reusing a compressed buffer before the writer consumes it. A slow FIFO makes “the main thread never waits” incompatible with bounded memory. Specify bounded queues, buffer ownership until writing finishes, and backpressure reaching `out_write`; test a stalled reader and incompressible data.

2. **Should fix — [unfinished-file detection](/home/luisc/Work/bend-projects/framebender-gz/notes/compress.md:712), [failure tests](/home/luisc/Work/bend-projects/framebender-gz/notes/compress.md:839).** Confirmed under `/tmp`: bgzip 1.24 returns **0** from `bgzip -t` when only the EOF block is missing; it prints a warning. Also, a close failure or signal after EOF was written can leave an EOF block despite failure. Check the marker explicitly, correct the expected test result, and state that callers must check the process status.

3. **Should fix — [input identity check](/home/luisc/Work/bend-projects/framebender-gz/notes/compress.md:698).** Comparing against input *pathnames* after opening the inputs can miss the actual input inode if a pathname changes. Compare with `fstat` of the open VCF/FASTA descriptors, retain the opened `.fai` identity, and fail before truncation if identity checks fail.

4. **Should fix — [output file handling](/home/luisc/Work/bend-projects/framebender-gz/notes/compress.md:693).** `… -o out.vcf.gz 2>out.vcf.gz` opens the same file twice; stderr messages can overwrite BGZF bytes while every machine law still holds. Refuse an output inode shared with stderr before truncating, or explicitly exclude shared output/message destinations from the guarantee.

5. **Minor — [law output’s explanation](/home/luisc/Work/bend-projects/framebender-gz/data/tmp/gz/draft/framebender/MACHINE.bend:277).** The abstract invariance statement is sound: for an accepted base command, `machine` prevents an irrelevant `None == None` justification; `usage` covers rejected commands. Qualify the prose as invariance of the **machine report**: adding `-o in.vcf` intentionally changes the real invocation’s messages and exit code through a trusted driver error. The trusted boundary is otherwise stated plainly; the independent-tool test plan is reasonable after the fixes above.

6. **Minor — [optional `output_ok` and fallback](/home/luisc/Work/bend-projects/framebender-gz/notes/compress.md:902).** None of these laws constrains `Args.output`; a broken selector returning `None` could silently send plain text to stdout while all laws hold. Make the small parse/output acceptance equivalence part of the proof plan, and treat an unexpected `None` as an internal error.

7. **Minor — [parser examples](/home/luisc/Work/bend-projects/framebender-gz/data/tmp/gz/draft/framebender/examples.bend:182).** The drafted grammar is unambiguous and preserves previously accepted `Cfg`, including `Opts.args`: pending values take precedence over option recognition. Add explicit examples for missing `-O`, refused `-oFILE`, invalid-first repeated `-o`, repeated `-O` resetting the level, and bare input `-o` versus `./-o`. These make the compatibility claim easier to audit.

8. **Minor — [the five reviewer questions](/home/luisc/Work/bend-projects/framebender-gz/notes/compress.md:969).** My choices: **keep extension precedence**, documenting conflicts prominently; **omit output options from the header**; **complete BGZF on a machine error**, while explaining that EOF means stream completion rather than normalization success; **keep default level 6**, with level 1 available explicitly; **refuse input aliases**, using descriptor identities as above.
